API reference

A read-only JSON API that answers "is this person inducted on this?", keyed by UniKey. It's meant for the tap-card add-on, which links card IDs to UniKeys and asks this app for the decision.

Connecting

From another add-onhttp://local-spl-registry:8099/api/v1 (Home Assistant's internal network; for a local add-on the hostname is local- plus the slug with dashes. If it doesn't resolve, check the hostname on this add-on's Info page.)
From elsewhere{{ settings.base_url }}/api/v1, over HTTPS
KeyHeader Authorization: Bearer spl_… or X-API-Key: spl_…. Create keys on the API keys page.
ExpiryAccess ends on the expiry date{% if settings.access_grace_days %}, plus {{ settings.access_grace_days }} days' grace{% endif %} (add-on option access_grace_days).

Rules

A person may use a resource when they have a completed (confirmed or manually entered), unexpired, non-cancelled record for an induction that grants it, and current records for every induction it requires (e.g. the room's space induction). Unconfirmed sign-offs don't count. The "SWP updated since induction" flag doesn't block access.

GET /api/v1/access/check?unikey=abcd1234&resource=j11-n209b

The decision for one person and one resource. Always returns 200 with allowed true or false and a reason:

reasonallowedmeaning
currenttrueInducted and in date; access_until is when it lapses (null = no expiry)
expiredfalseThe induction has expired
prerequisite_missingfalseInducted on it, but a required induction (listed in requires_missing) is missing or expired
not_inductedfalseNo completed induction that grants it
unknown_personfalseNo inductions recorded for that UniKey
unknown_resourcefalseNo loaded induction grants that resource id

GET /api/v1/access

Everyone who currently has access to anything, and to what, for a card system to keep a local copy (so readers keep working if this app restarts). Send the ETag back as If-None-Match when polling: you get 304 Not Modified until something changes.

{
  "grace_days": 0,

  ],
  "generated_at": "2026-10-30T00:12:03+00:00"
}

GET /api/v1/people/abcd1234

One person's inductions (status current or expired, expiry, prerequisites) and the resources they can use now. 404 if the UniKey isn't known.

GET /api/v1/resources

Every resource id, its name and room, and which inductions grant it. Resource ids come from grants_access in the induction files; set fixed ids there (- form4: Formlabs Form 4) before readers depend on them.
